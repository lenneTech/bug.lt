## Automatic

With `autoShow: true` (the default) the module adds the button to every page. Nothing else is needed.

## From code

```vue
<template>
  <BugReportButton />
  <!-- or your own trigger -->
  <button @click="openModal">Bug melden</button>
</template>

<script setup lang="ts">
const { openModal } = useBugReport();
</script>
```

`useBugReport()` returns:

| Value | Type | Description |
|---|---|---|
| `openModal` | `() => Promise<void>` | Takes the screenshot and opens the form |
| `submitBugReport` | `(data: BugReportData) => Promise<void>` | Sends a report |
| `getUserJourney` | function | The recorded user journey |
| `isSubmitting` | `Ref<boolean>` | A report is being sent |
| `error` | `Ref<string \| null>` | Error of the last submit |
| `previewScreenshot` | `Ref<string \| null>` | The screenshot of the open form |
| `capturingScreenshot` | `Ref<boolean>` | The screenshot is being taken |
| `lastError` | – | The last JavaScript error the module caught |

## Components

| Component | Description |
|---|---|
| `<BugReportButton />` | The button, with the position and color of the configuration |
| `<BugReportModal />` | The form dialog |
| `<ErrorBoundary />` | Catches errors of its content |
| `<UserJourneyTimeline />` | Timeline of the recorded actions |
| `<BugIcon />` | The bug icon |

## UI modes

The module ships two separate implementations, chosen with `ui`.

**`ui: true` (default).** Button, form and toasts are built with [`@nuxt/ui`](https://ui.nuxt.com). The module installs
`@nuxt/ui` and fits into apps that already use it (Tailwind CSS 4).

**`ui: false`, self-contained.** Own button, form and toasts, without any `@nuxt/ui` import and without the `#ui` alias;
`@nuxt/ui` is not installed. The components bring their styles as scoped CSS and inline SVG icons, so the module works
in any Nuxt project, for example with Tailwind CSS 3 (`@nuxtjs/tailwindcss`) or without Tailwind:

```ts
export default defineNuxtConfig({
  modules: ['@lenne.tech/bug.lt'],
  bug: {
    ui: false,
    position: 'bottom-right',
  },
});
```

In this mode `buttonIcon` is not supported, because no icon framework is included. Without `buttonText` the button
shows the built-in bug icon.
