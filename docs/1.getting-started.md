## Installation

```bash
npm install @lenne.tech/bug.lt
```

## `nuxt.config.ts`

```ts
export default defineNuxtConfig({
  modules: [
    '@lenne.tech/bug.lt',
    // @nuxt/ui is added automatically (unless ui: false)
  ],
  bug: {
    enabled: true,
    position: 'bottom-right',
  },
});
```

Every option has a default, see [Configuration](./2.configuration.md). With `ui: true` (the default) the module installs
`@nuxt/ui`; for a project without `@nuxt/ui` or Tailwind CSS 4 use `ui: false`, see [Usage](./4.usage.md#ui-modes).

## Linear credentials for local development

For local development, put the credentials into `.env` and pass them in `nuxt.config.ts`:

```bash
# .env
NUXT_LINEAR_API_KEY=lin_api_...        # Linear → Settings → API
NUXT_LINEAR_TEAM_NAME=<team name or key>
NUXT_LINEAR_PROJECT_NAME=<project name> # optional
```

```ts
bug: {
  linearApiKey: process.env.NUXT_LINEAR_API_KEY,
  linearTeamName: process.env.NUXT_LINEAR_TEAM_NAME,
  linearProjectName: process.env.NUXT_LINEAR_PROJECT_NAME,
},
```

This works **only locally**: `process.env` in `nuxt.config.ts` is read at build time, and a container build does not
have the secrets. Deployed stages set the credentials at runtime instead, see
[Linear](./3.linear.md#deployed-stages).

Older versions read `LINEAR_API_KEY`, `LINEAR_TEAM_NAME` and `LINEAR_PROJECT_NAME`; rename them.

## Check it

Start the app. The button appears in the chosen corner; a test report creates an issue in the Linear team. If the
report answers `500 "Linear API is not configured"`, the server has no API key.
