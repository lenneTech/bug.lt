The options go into the `bug` key of `nuxt.config.ts`.

| Option | Type | Default | Description |
|---|---|---|---|
| `enabled` | `boolean` | `true` | Turns the whole module on or off. Read at build time |
| `ui` | `boolean` | `true` | `true`: components with `@nuxt/ui`; `false`: self-contained, see [UI modes](./4.usage.md#ui-modes) |
| `endpoint` | `string` | `'/_bug-lt/report'` | Server route the report is sent to (see below) |
| `linearApiKey` | `string` | – | Linear API key, server only |
| `linearTeamName` | `string` | – | Linear team name or key |
| `linearProjectName` | `string` | – | Linear project name (optional) |
| `autoShow` | `boolean` | `true` | Show the button automatically |
| `position` | `string` | `'bottom-right'` | `'bottom-right'`, `'bottom-left'`, `'top-right'` or `'top-left'` |
| `buttonColor` | `string` | `'#ef4444'` | Button color |
| `buttonText` | `string` | – | Button text instead of the icon |
| `buttonIcon` | `string` | – | Icon name (not in the self-contained mode) |
| `enableScreenshot` | `boolean` | `true` | Take a screenshot |
| `enableBrowserInfo` | `boolean` | `true` | Collect browser details |
| `enableConsoleLogs` | `boolean` | `true` | Collect console output |
| `enableNetworkRequests` | `boolean` | `true` | Collect network requests |
| `enableUserJourney` | `boolean` | `true` | Track the user journey |
| `enableErrorBoundary` | `boolean` | `true` | Catch JavaScript errors |
| `autoOpenOnError` | `boolean` | `false` | Open the form on a JavaScript error |
| `theme` | `string` | `'auto'` | `'light'`, `'dark'` or `'auto'` |
| `maxConsoleLogs` | `number` | `50` | Maximum number of console entries |
| `maxNetworkRequests` | `number` | `50` | Maximum number of network requests |
| `userJourney` | `object` | see below | User journey options |

The Linear values go to the server's runtime configuration only (`runtimeConfig.bugLt`); every other option is public
(`runtimeConfig.public.bugLt`) and can be changed per stage with `NUXT_PUBLIC_BUG_LT_*`, for example
`NUXT_PUBLIC_BUG_LT_AUTO_SHOW=false`.

## The endpoint is not under `/api/`

Many Nuxt apps forward every `/api/**` request to a separate backend through a Nitro `routeRules` proxy. Such a
catch-all would swallow a report sent to `/api/…` and pass it to the backend, which answers 404, so the module's
handler never runs. That is why the default is `/_bug-lt/report`, in Nuxt's internal `_` prefix style. Server and
client read the same value; change it freely as long as no proxy catches it.

## User journey options

| Option | Type | Default | Description |
|---|---|---|---|
| `enabled` | `boolean` | `true` | Track the user journey |
| `maxEvents` | `number` | `50` | Maximum number of events |
| `captureClicks` | `boolean` | `true` | Clicks |
| `captureNavigation` | `boolean` | `true` | Page changes |
| `captureFormInteractions` | `boolean` | `true` | Focus, blur and submit |
| `captureKeyboard` | `boolean` | `true` | Important key presses |
| `captureErrors` | `boolean` | `true` | JavaScript errors |
| `captureModalEvents` | `boolean` | `true` | Modal events |
| `captureHover` | `boolean` | `false` | Hover events |
| `captureScroll` | `boolean` | `false` | Scrolling |
| `captureInputChanges` | `boolean` | `false` | Changes of input fields |
| `captureInputValues` | `boolean` | `false` | The values typed into fields (never for password, token and similar fields) |
| `throttleRate` | `number` | `100` | Throttle rate in ms |
